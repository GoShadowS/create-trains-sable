# Support

## Bugs and crashes

Open an issue at https://github.com/GoShadowS/create-trains-sable/issues. Include:

- Minecraft, NeoForge, Create, Sable and Create Trains Sable versions.
- The full `latest.log` (or `debug.log` if you have it) from `logs/` and the crash report if the game crashed.
- Your `config/createtrainssable-server.toml`, or at least the values you changed.
- A short description of the track layout and what the train was doing when the problem appeared.

Please search existing issues first. Crashes that also happen with this add-on
disabled belong to Create or Sable and should be reported to those projects.

## Questions

Use GitHub Discussions at
https://github.com/GoShadowS/create-trains-sable/discussions if Discussions is
enabled for the repository. Otherwise, open an issue with the `question` label.

The configuration keys and the current feature set are described in
[README.md](README.md).

There is no Discord server, forum, paid support or release hotline at the moment.
Issues are the only channel with a written history, so they get priority.

## What this project cannot help with

- Create's own train, station and signal behaviour when this add-on is disabled.
- Sable's native Rapier library, its renderer, or crashes that happen before this
  add-on loads.
- Minecraft launchers, modpack launchers and Java runtimes on your machine.
